# PDF Clip

PDFから必要なページだけを選んで、別のPDFとして保存できる無料のブラウザツールです。

## 利用する

**https://makiabe.github.io/PDFClip/**

インストールやアカウント登録は不要です。

## 主な機能

- PDFのページをサムネイルで確認して選択・抽出
- ページ番号指定（例：`1-3, 5, 8`）、全選択、解除、奇数・偶数、反転
- 選択ページを1つのPDFに保存、または1ページずつ分割してZIPに保存
- ページの回転と、不要ページを除いた新しいPDFの作成
- JPG・PNG画像への一括変換、複数形式の同時出力
- 拡大プレビュー、使い方・設定ヘルプ、ダークモード

## 使い方

1. PDFをドロップするか、クリックしてファイルを選択します。
2. 保存するページと出力形式を選びます。読み込み直後は全ページが選択されています。
3. 生成ボタンを押して保存します。出力が1ファイルの場合は直接保存、複数の場合はZIPになります。

「不要ページを削除する」をオンにすると、赤いチェックが削除対象になります。切り替え時は保存対象を維持するため選択状態が反転します。元のPDFは変更しません。

ページごとの回転と、保存対象全ページへの追加回転を設定できます。回転はPDF・分割PDF・JPG・PNGに反映されます。

## ファイルの取り扱いと制限

PDFの読み込み・表示・変換はブラウザ内で処理し、PDFの内容やファイル名をサーバーに送信する処理はありません。画面配色の設定以外はブラウザの保存領域に記録しません。

ページやフォント、処理用ライブラリの取得にはインターネット接続が必要です。完全オフライン用アプリではありません。

- 1ファイル100MBまで。処理可能なページ数やサイズは端末のメモリに依存します。
- パスワード付き・暗号化されたPDFには対応していません。
- 電子署名、特殊なフォーム等は維持されない場合があります。保存結果をご確認ください。
- JPG・PNGは通常144dpi相当で生成します。大きなページはブラウザの負荷を抑えるため縮小します。

## 構成

`index.html`、`style.css`、`app.js`、`core.js`、`pdf-engine.js`、`assets/`、`favicon.png`を同じ階層構成で配置します。ビルド工程はありません。ファイルの参照は相対パスなので、サブディレクトリで公開できます。

ローカルでの確認：

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

## テスト

```sh
node --check app.js
node --check core.js
node --check pdf-engine.js
node --test tests/core.test.cjs
```

範囲指定、削除対象、回転角、出力計画などの単体テストを含みます。これらは実PDFでの読み込み・変換・保存の通し試験を代替するものではありません。

## 使用ライブラリ

処理時に固定バージョンのPDF.js、pdf-lib、JSZipを取得します。各ライブラリのライセンスは配布元をご確認ください。
